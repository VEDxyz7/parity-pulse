## Common contracts

**B** (Binance signed REST): base `https://web3.binance.com/build`; headers X-OC-APIKEY, X-OC-TIMESTAMP, X-OC-SIGN; optional X-OC-RECV-WINDOW and X-OC-NONCE. HMAC-SHA256/Base64 over exact timestamp + uppercase method + raw /build path/query + raw body. UTC ISO8601 milliseconds; window default5000/max60000ms. Default limits: IP/key 1200/minute, user6000/minute, endpoint5RPS. Respect actual rate headers/Retry-After. [Authentication](https://web3.binance.com/en/dev-docs/authentication).

**F** (failure policy): validate HTTP, integer code=0, success=true, envelope code/msg/data/timestamp/success and endpoint payload. Authentication/permission errors stop; reads retry transient errors under bounded backoff; 429 respects Retry-After. Malformed, stale, conflicting or unknown data fails closed. Writes need operation-specific idempotency and reconciliation, never indiscriminate retries. Response timestamp is not necessarily market observation time.

Q=query, B=JSON body, P=path; ?=optional. All following paths start `/api/v1/dex/`. Data strings representing money/base units stay exact; absence/null never converted to valid zero. Actual source contracts linked by family.

## Critical Trading details

- Quote amount is integer sell-token base units; wallet CLI quantity is human-readable. Resolve decimals, chain and contract first.
- Quote vendor filter currently allows LiquidMesh/Pancake/Jupiter; RFQ submit vendor enum currently InchFusion/CowSwap/PcsXRfq. These are different selector contracts; do not pass one enum blindly into another.
- Build requires slippagePercent unless autoSlippage=true; optional gas/approval/price-impact controls require policy validation. Provider defaults are not platform risk limits.
- Use returned executionMode; normal SWAP has tx; RFQ has typed data and vendor order context. Issuer support is not a hard-coded execution-mode map.
- Distinguish /quote quoteId → /swap quoteId from /swap rfq.orderId → /order/submit quoteId, then platform orderId → status polling. Reuse submit requestId on same attempt within documented 30-minute duplicate window; persistent reconciliation beyond that is mandatory.
- Flash API exposes enableRFQ and potentially embedded RFQ calldata, while ordinary equity/RWA flow is documented as RFQ. This optional surface is not selected as a safety workaround.
- Actual RFQ payload nested schema, signer recovery-format conversion, vendor constraints and deadline must be validated with fixtures before use. Current status: LIVE RFQ BLOCKED.
