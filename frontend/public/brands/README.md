# Bundled identification assets

These unmodified favicons were retrieved from official brand websites on 11 October 2026. Source URLs, byte counts and SHA-256 digests are in `provenance.json`. They are served locally; the application never contacts a logo service during rendering. An image error falls back to stable ticker/issuer initials.

| Identity | Official asset | Usage here |
|---|---|---|
| Nvidia / NVDA | https://www.nvidia.com/favicon.ico | Underlying-company identifier |
| Apple / AAPL | https://www.apple.com/favicon.ico | Underlying-company identifier |
| Google / GOOG, GOOGL | https://www.google.com/favicon.ico | Google business identifier for Alphabet shares; not an Alphabet corporate-logo claim |
| Ondo | https://ondo.finance/favicon.ico | Only when the actual issuer name is Ondo / Ondo Finance |

Atlas model and Meridian model are fictional scenario issuers. They use explicitly labeled initials, never an Ondo or other real issuer logo. BStock and unsupported issuers keep their actual name and initials. Microsoft retrieval timed out twice, and Tesla returned HTTP 403; neither failure is replaced with an invented brand asset. MSFT, TSLA, AMZN, META and unknown tickers have stable initials fallbacks.

Availability is not a redistribution license. These assets remain proprietary brand identifiers, with no endorsement or blanket open-source/CC0 claim. Official rights guidance was inspected: [Nvidia terms](https://www.nvidia.com/en-eu/about-nvidia/terms-of-service/), [Apple trademark guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html), [Google brand guidance](https://about.google/brand-resource-center/guidance/). Public/commercial distribution rights have not been established by this local UI increment. Ondo's terms page did not return inspectable content. No rights grant is inferred from the public favicon URL.
